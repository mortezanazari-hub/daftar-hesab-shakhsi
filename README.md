# دفتر حساب شخصی

دفتر مالی فارسی و آفلاین برای ثبت بدهی، طلب، اقساط، چک‌ها و مدیریت دُنگ‌های مشترک.

## حریم خصوصی و ذخیره اطلاعات

اطلاعات مالی در IndexedDB مرورگر همان دستگاه ذخیره می‌شود و به GitHub یا سرور دیگری ارسال نمی‌شود. هر مرورگر و هر گوشی دفتر مستقل خود را دارد. پاک‌کردن داده‌های مرورگر، اطلاعات دفتر را نیز پاک می‌کند.

## اجرای نسخه استاتیک

```bash
npm install
npm run static:build
```

خروجی آماده انتشار در پوشه `static-dist` ساخته می‌شود. انتشار GitHub Pages با هر بار ارسال تغییر به شاخه `main` به‌صورت خودکار انجام می‌شود.
