# دفتر حساب شخصی

دفتر مالی فارسی، آفلاین و mobile-first برای ثبت بدهی و طلب شخصی، چک‌ها، وام و خرید اقساطی بانکی/فروشگاهی و مدیریت دُنگ‌های مشترک.

## قابلیت‌های اصلی

- دفتر کل یکپارچه هر شخص با جمع ثبت‌های مستقیم و اثر خالص دُنگ‌ها نسبت به «من»
- گروه‌های دُنگی با عضویت صریح و سهم پیش‌فرض قابل صفر شدن
- انتخاب شرکت‌کننده‌ها و وزن سهم جداگانه برای هر خرید
- ریز خریدها، سهم مبلغی هر عضو و پیشنهاد تسویه
- ثبت پرداخت واقعی تسویه و محاسبه مجدد مانده‌ها
- ویرایش/حذف ثبت‌های مستقیم و خریدهای دُنگی
- جست‌وجو و فیلتر دفتر اشخاص و گروه‌ها
- ورودی مبلغ با جداکننده سه‌رقمی خودکار
- ماژول مستقل وام و خرید اقساطی با طرف حساب بانکی/فروشگاهی، مبلغ کل قرارداد، پیش‌پرداخت، تعداد و فاصله اقساط، تقویم شمسی، مانده و اقساط عقب‌افتاده
- ثبت پرداخت کامل یا جزئی هر قسط با تاریخچه پرداخت و قفل ایمن زمان‌بندی بعد از شروع پرداخت
- تجمیع سررسید چک‌ها، بدهی‌های تاریخ‌دار و اقساط در یک تقویم
- خروجی پشتیبان JSON و بازیابی کامل اطلاعات

## حریم خصوصی و ذخیره اطلاعات

اطلاعات مالی در IndexedDB مرورگر همان دستگاه ذخیره می‌شود و به GitHub یا سرور دیگری ارسال نمی‌شود. هر مرورگر و هر گوشی دفتر مستقل خود را دارد. پاک‌کردن داده‌های مرورگر می‌تواند اطلاعات دفتر را نیز پاک کند؛ بنابراین برای اطلاعات مهم از بخش «پشتیبان و بازیابی» نسخه پشتیبان بگیرید.

نسخه دیتابیس محلی به‌صورت migration-safe ارتقا می‌یابد و داده‌های نسخه قبلی در هنگام به‌روزرسانی برنامه حفظ می‌شوند.

## اجرای نسخه استاتیک

```bash
npm install
npm run static:build
```

خروجی آماده انتشار در پوشه `static-dist` ساخته می‌شود. انتشار GitHub Pages با هر بار ارسال تغییر به شاخه `main` به‌صورت خودکار انجام می‌شود.

- ویرایش و حذف خود گروه دُنگی، مدیریت اعضای فعال و حفظ تاریخچه اعضای سابق

- دفتر مستقل چک‌های دریافتی و پرداختی با بانک، شناسه صیادی، صادرکننده، ذی‌نفع، واگذارکننده، سررسید، بابت و وضعیت وصول/برگشت
